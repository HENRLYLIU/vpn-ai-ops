# 面向非技术用户的 AI 全程实施入口

## 原始需求与确认方向

用户明确要求：文档面向非技术用户，提前准备 AI 所需环境与工具，实施尽量全部交给 AI。用户提供 VPS 和域名资源，完成必要授权，不承担命令执行、技术参数填写和日常排错。

## 范围

重写 README 使用入口、环境准备清单及 AI 部署提示词；同步运维约定、发布说明与验收清单。保留已有 Python CLI 与安全边界，不在本次文档变更中实现密码登录或 MCP 适配代码。

## 验收标准

- 用户入口不要求用户填写 Zone ID、编写配置或逐条执行部署命令。
- AI 手册写清资源发现、缺省值、权限检查、部署、故障恢复与分层验收。
- 说明 SSH 密码首次接入的工具前提；现有 CLI 仍要求已验证公钥登录。
- 说明 Cloudflare MCP 与现有 CLI Token 的关系，不承诺 OAuth 能自动生成或转交续期凭据。
- 缺少工具或权限时只向用户提出最小、具体的必要动作，保留已完成进度。
- 区分本地文档/离线验证与尚未完成的首次使用及云端端到端验收。

## 风险

不同 AI 环境的秘密输入、MCP 权限、浏览器与设备控制能力不同。不得以增加提示词为由宣称代码已经支持密码认证或无 Token 部署。
