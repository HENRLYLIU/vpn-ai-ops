# AI 全程实施任务

本页给执行 AI 阅读。用户通过 README 提交任务后，由你操作工具持续完成部署，不把命令清单交还给用户。先读 `AGENTS.md`、`docs/ai-environment.md`、`docs/setup.md` 和 `docs/operations.md`。

## 一、检查工具与资源

1. 核实实际执行环境的终端、网络、Python 3.10+、OpenSSH、Git、curl；在已有授权范围内安装缺失依赖。
2. 检查 SSH、Cloudflare API MCP、秘密输入/存储，以及可选的云厂商和客户端控制工具。区分“连接存在”与“操作权限已验证”。
3. 使用用户提供的 VPS IP、身份和域名；通过工具查询 Zone ID、DNS、系统与网络条件。按 setup.md 选择默认值，只集中询问无法查询的信息，如证书联系邮箱。
4. 无安全秘密入口时，明确请求准备该入口，不让用户把密码或 Token 发到聊天。独立终端的环境变量是否可用必须验证，不能假定共享。

## 二、完成一次接入准备

1. 通过可信来源核验 SSH 主机指纹。已有可用公钥登录就直接使用；只有密码时按 ai-environment.md 的安全交互路径接入，追加专用公钥并用独立连接验证。不覆盖原密钥、不关闭主机校验、不修改 sshd。
2. 核实 root 或 `sudo -n true` 可用。权限不足时请求具体授权，不擅自改 sudoers。
3. 使用 Cloudflare API MCP 查询正确 Zone、解析和 SSL/TLS 状态。MCP 未连接但已有 Token 时，可使用授权的 API 路径。对共享 Zone 设置或冲突记录先给出影响和方案。
4. 准备当前 CLI 必需的 CF_API_TOKEN。优先复用安全存储；只有在权限允许且秘密不会进入工具记录时才自动创建和交付。否则引导用户完成一次 Token 创建及安全输入，之后继续执行。不能把 MCP OAuth 当作 VPS 续期凭据。
5. 检查云安全组。已有云厂商工具和授权则自行配置对应规则；否则只请求用户放行实际 SSH、443 TCP/UDP、8443 TCP。服务器防火墙与云安全组分别检查。
6. 运行 init 并填写私有 config.local.json，不打印完整文件，不新写一键部署脚本。

## 三、执行部署

1. 运行 plan、preflight，简述目标、三条线路、目录和维护任务。用户要求搭建已授权 README 说明的常规实施，无需对每条命令重复确认。
2. 预检通过后执行 deploy。DNS 默认由脚本创建；已有完全匹配记录可复用。遇到非受管服务、DNS 冲突或资源不足，不绕过保护，不迁移或删除旧业务。
3. 命令失败时读取最小范围的诊断并脱敏，参考 troubleshooting.md；能在授权范围内修复则自行处理并继续。SSH 超时或中断后先确认远端任务状态，不并发重试。
4. deploy 成功后执行 status。确认正式证书、续期 cron、两个 systemd timer 和第一份备份；记录 warnings，不能只看容器 running。
5. 若需要启用 UFW，先确认规则与第二个 SSH 会话后在已授权范围内处理，不 reset、不影响原 SSH 端口。操作系统重启、旧业务迁移不在常规部署内。

## 四、验证并交付

1. 查找或从官方 Release 安装合适的 mihomo 核心，核对下载摘要，执行 verify。三条线路必须逐条验证，不使用 AUTO 的单次成功代替。
2. 某线路失败时定位并修复，不关闭正式 TLS 校验，不反复强制签发证书。无法完成的项目保留失败证据和下一步。
3. 将 artifacts 中的文件交付到用户可访问的私有位置，只报告文件路径，不展示正文、节点链接或二维码。
4. 具备设备控制能力时尽可能自动安装/导入和配置客户端；缺少能力时只请求最少导入操作。登录、付费购买、系统 VPN/TUN 权限由用户完成。修改本机路由前准备恢复方法。
5. 在实际设备分别验收预期直连、代理出口、TUN 和 DNS。没有设备证据就标记未验证，不把本地临时核心测试当作设备验收。
6. 清理本地临时凭据环境，保留 VPS 自动续期所需受限凭据。解释服务和维护不依赖 AI 持续在线，备份暂在本机且无默认外部告警。

## 五、最后的报告

报告只包含必要证据：

- 服务端：版本、检查结果、证书、维护任务、首份备份和 warnings。
- 三线路：逐条成功/失败、实测出口是否匹配目标。
- 用户设备：已导入/待导入，TUN、直连和 DNS 实际验证结果。
- 私有客户端文件位置，日后让 AI 巡检、备份、升级的入口。
- 未完成项：具体缺少的能力或权限、用户最少动作、你接下来会执行什么。

持续执行到完成，或确实需要用户输入/外部权限。不要用一段待执行命令代替已获授权的实施。官方接口或版本发生变化时查阅 docs/sources.md 中的当前官方说明。
