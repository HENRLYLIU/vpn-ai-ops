# 交给 AI 的维护任务

日常巡检：

```text
请阅读本仓库 AGENTS.md 和 docs/operations.md，对 config.local.json 指定的受管 VPS 进行巡检。
先运行 status，检查服务状态、版本、证书、磁盘、权限、定时器和最近备份。
检查是否有待重启提示以及定时任务失败；按需读取脱敏日志摘要，不输出密钥或 Token。
必要时运行 verify 验证三条线路。报告异常的证据、影响和建议处理顺序。
本次只巡检，不升级、不重启、不修改 DNS 或凭据。
```

指定版本升级：

```text
请将本项目管理的 sing-box 升级到我指定的精确稳定版本：<X.Y.Z>。
先读官方 release notes 和 migration，确认现有配置兼容，再运行 status。
确认当前状态可用后执行 upgrade --version <X.Y.Z>，记录自动生成的回滚快照名。
随后运行 verify，并检查证书续期及维护定时器仍正常。
若任一线路在升级后回归失败，使用该快照 rollback，并重新验证三条线路。
不做操作系统升级、Docker 升级或服务器重启；这些需要另一个维护计划。
报告前后版本、备份名、实际验证结果及剩余事项，不输出秘密。
```

AI 定期巡检任务可以使用上面的只读提示词，由用户自己的 AI 工具定时运行。仓库本身不绑定某一家 AI 平台，也不保存模型 API Key。VPS 的基础定时维护不依赖 AI 平台。
